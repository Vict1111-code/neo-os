# NEO-OS Agent Workflow

1. **Inspect:** read root/nested agent instructions, issue, current GitHub tree and project state.
2. **Link:** identify PRD requirement and roadmap phase.
3. **Plan:** state changed files, dependencies, risks and test plan.
4. **Implement:** smallest coherent vertical slice, integrating mature Linux components where appropriate.
5. **Validate:** execute relevant automated/manual tests; record actual results, including failures.
6. **Secure:** review file/network access, authorization, credentials, licensing, resource usage and recovery.
7. **Document:** update technical docs, ADRs and `docs/PROJECT_STATE.md`.
8. **Handoff:** communicate verified changes, residual risks and next task.

No claim of completion based only on generated designs, unrun code, or text descriptions.
