# ADR-007 — Package manager selection before custom implementation

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-08, FR-15

## Context
NEO Market needs reliable package ownership and upgrades.

## Decision proposed
Evaluate mature package manager backend before adopting bespoke package format.

## Alternatives to assess
Custom format immediately; no package tracking.

## Trade-offs and consequences
Evaluation phase required; avoid hard dependency on unproven package tool.

## Validation required before acceptance
Prototype file ownership, signed package verification, conflict handling and upgrade/remove.

## Approval and evidence
Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
