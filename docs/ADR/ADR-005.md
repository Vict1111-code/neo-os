# ADR-005 — Authenticated local IPC and privileged broker

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-06, FR-11

## Context
AI, GUI and apps need system functions without root-level access.

## Decision proposed
Expose versioned D-Bus contracts; use minimal independently authenticated privileged broker.

## Alternatives to assess
Direct sudo commands; unrestricted shell daemon; ad hoc local HTTP.

## Trade-offs and consequences
Strong privilege boundaries add review burden; safer failure isolation.

## Validation required before acceptance
Cross-user unauthorized and malformed calls rejected; confirmation required for risky changes.

## Approval and evidence
Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
