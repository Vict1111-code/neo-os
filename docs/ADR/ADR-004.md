# ADR-004 — Qt QML desktop atop an existing Wayland compositor

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-02, FR-03, FR-04

## Context
Need usable visual prototype and real app launches before advanced window management.

## Decision proposed
Prototype with Qt 6/QML on existing compositor before custom compositor research.

## Alternatives to assess
GTK; Electron; full custom compositor immediately.

## Trade-offs and consequences
Faster UI progress; some shell/window behavior constrained by compositor.

## Validation required before acceptance
Qt desktop launches .desktop application; keyboard/reduced motion verified.

## Approval and evidence
Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
