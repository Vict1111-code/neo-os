# ADR-008 — Authenticated updates and recovery gates

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-15

## Context
Update failures can make a source-built OS unusable.

## Decision proposed
Require signed metadata/artifacts and an update recovery path before stable release.

## Alternatives to assess
Unverified download/overwrite; updates without recovery.

## Trade-offs and consequences
Requires key management and robust update tooling; stable release delayed until tested.

## Validation required before acceptance
Corrupt packages rejected; interrupted VM upgrade recovered.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
