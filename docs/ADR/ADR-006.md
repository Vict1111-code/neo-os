# ADR-006 — Verified sources and reproducible recipes

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-01, FR-15

## Context
LFS instructions alone do not provide reproducible distribution builds.

## Decision proposed
Version-pin sources, record checksums, patches, licenses, build manifests and logs.

## Alternatives to assess
Manual untracked builds; mutable latest sources.

## Trade-offs and consequences
More maintenance upfront; traceable build artifacts and update inputs.

## Validation required before acceptance
A clean VM rebuild documents inputs and outputs, with checksum verification.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
