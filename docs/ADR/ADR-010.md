# ADR-010 — QEMU-first safe testing

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-01, FR-15

## Context
Host safety and limited hardware resources.

## Decision proposed
Build and boot on disposable virtual disks before any physical machine install.

## Alternatives to assess
Develop directly on host disk; assume screenshots are proof.

## Trade-offs and consequences
GPU and device issues require later real hardware tests.

## Validation required before acceptance
QEMU console boot/shutdown log and isolated image hash; never touch host partitions.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
