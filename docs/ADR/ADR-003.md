# ADR-003 — Rust-first original native services

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-06, FR-11

## Context
Linux and GNU userspace are not fully Rust.

## Decision proposed
Use Rust for new non-UI system services; retain C/C++/QML where required.

## Alternatives to assess
C-only; Go-first; rewriting third-party components.

## Trade-offs and consequences
Reduces memory bugs in original services; introduces FFI and integration complexity.

## Validation required before acceptance
One small nonprivileged Rust service builds, runs and passes tests.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
