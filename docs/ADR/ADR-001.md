# ADR-001 — LFS and BLFS systemd foundation

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-01, FR-15

## Context
Base distribution with package/image reproducibility still to be engineered.

## Decision proposed
Use version-pinned LFS/BLFS as the initial base; upstream kernel with minimal patches.

## Alternatives to assess
Debian/Fedora remix; Buildroot; Yocto.

## Trade-offs and consequences
LFS improves understanding/control but requires original distribution lifecycle engineering.

## Validation required before acceptance
Console boot in QEMU with build manifests; repeatable documented build.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
