# ADR-002 — x86-64 as initial hardware target

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-01, FR-13

## Context
Small team and 8 GB development machine; drivers/boot vary per architecture.

## Decision proposed
Start with x86-64 QEMU and a limited set of physical PCs; ARM64 later.

## Alternatives to assess
ARM64 first; simultaneous architectures.

## Trade-offs and consequences
Focus reduces combinatorial hardware and toolchain complexity.

## Validation required before acceptance
Kernel boots and core peripherals work on declared QEMU target; only later list tested PCs.

Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
