# ADR-009 — AI isolated from privileged execution

- **Status:** Proposed (not accepted)
- **Date:** 2026-11-16
- **Phase:** 0 — Architecture and Technical Foundation
- **Related requirements:** FR-06, FR-11

## Context
Models and retrieved content can contain misleading or malicious instructions.

## Decision proposed
AI inference runs unprivileged; actions are structured proposals evaluated by broker.

## Alternatives to assess
Agent with root shell; GUI-owned privilege credentials.

## Trade-offs and consequences
Additional authorization UX but limits blast radius.

## Validation required before acceptance
Prompt injection and missing-consent tests fail closed; AI off leaves desktop working.

## Approval and evidence
Decision reviewer: not assigned. Approval: pending. Implementation evidence: none yet.
