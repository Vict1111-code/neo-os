# ADR-011 — Matrix CLI first embedded terminal architecture

- **Status:** Proposed (experimental)
- **Date:** 2026-11-16
- **Issue:** #5

## Context
NEO Desktop currently launches an external terminal via `backend.launchMatrix()`. A usable integrated terminal requires a PTY, shell lifecycle, output presentation, event routing, terminal control sequences and security limits.

## Options evaluated
1. **Mature terminal widget with proper VT emulation** — generally more correct, but requires library selection, Qt 6 integration and licensing review (e.g. QTermWidget).
2. **Direct PTY with Qt frontend** — fastest way to learn Linux terminal plumbing, but text-only output is not a full terminal emulator.
3. **Web terminal frontend** — an embedded web stack could leverage existing emulators, but adds deployment and security surface.

## Proposed decision
Build a strictly labeled **experimental** `forkpty()`-based line-oriented prototype, linked with libutil on Linux; retain external-terminal fallback. In the next iteration, choose a maintained terminal emulator implementation for VT/ANSI correctness before claiming full terminal support.

## Trust model
- Start `/bin/bash --noprofile --norc -i` as the current user; do not use sudo/root.
- UI input is an explicit command initiated by the user, never AI-sourced or run automatically.
- Terminal access is powerful: it is not a sandbox, and the shell inherits current-user permissions.
- Closing the panel currently **hides** it; Stop terminates the session and the shell is stopped at application shutdown.
- Reap child process and avoid uncontrolled subprocess lifetime; test termination behavior manually.

## Limitations and follow-up
- Basic text rendering strips some ANSI SGR/control sequences, but is incomplete; cursor controls and full-screen applications are unsupported.
- Output chunks may split multibyte characters; streaming UTF-8 decoding needs improvement.
- Terminal size is fixed at startup (80x24); resizing protocol and real interactive keystrokes remain open.
- Redirected output may be merged through PTY; the visual UI does not distinguish stdout/stderr reliably.
- Robust process group cleanup, job control, Unicode, clipboard and accessibility need further evaluation.

## Acceptance before advancing to full feature
- GitHub CI builds on Ubuntu; user tests `pwd`, `echo NEO-OS`, Ctrl+C, Stop/Start and closing/reopening.
- Avoid calling this a production-quality terminal emulator.
